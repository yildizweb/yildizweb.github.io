# Third-party assets

All third-party media is stored locally. The project gallery remains the only part of the site that displays user-provided construction photography.

## Brand and typography

- Header and footer: `PNG LOGO/H- BEYAZ.png`, converted to `assets/brand/yildiz-logo-white.webp`. The original has a transparent background.
- Structured-data logo: `PNG LOGO/H - SİYAH.png`, converted to `assets/brand/yildiz-logo-carbon.webp`. The original has a transparent background.
- Display typeface: Barlow Condensed 700/800/900 from Google Fonts, licensed under the SIL Open Font License. Local licence copy: `assets/fonts/OFL-BarlowCondensed.txt`.
- The background-included logo files are not referenced by any generated page.

## User-provided project photography

- Images under `Media/Images` are used only in the project-photo gallery and lightbox.
- The uploaded portrait is not rendered. The managing-director sections use a typographic brand panel so that no unrelated stock person is presented as Ali Derman YILDIZ.
- Reference companies are presented as typographic name cards because approved logo files and usage rights were not supplied.
- Google Maps is loaded only after explicit visitor consent; no Google Maps asset is stored locally.
